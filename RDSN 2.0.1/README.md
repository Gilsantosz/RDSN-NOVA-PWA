# RDSN v2.0.1 - Instruções de Instalação

Esta pasta contém a versão final do RDSN 2.0.1 pronta para ser instalada em outra máquina.

## Conteúdo da Pasta:
- **RDSN-2.0.1.dmg**: Instalador padrão para macOS. Basta abrir e arrastar para a pasta Aplicativos.
- **RDSN-2.0.1-mac.zip**: Versão comprimida do aplicativo para macOS.

## Como instalar em outra máquina:
1. Copie esta pasta inteira para um pendrive ou envie via rede para a máquina de destino.
2. Na máquina de destino, abra o arquivo `RDSN-2.0.1.dmg`.
3. Arraste o ícone do RDSN para a pasta `Applications`.
